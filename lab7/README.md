# Лабораторная работа 7: MQTT Издатель-Подписчик (Вариант 4)

## Описание проекта

Проект реализует передачу сообщений по протоколу MQTT в соответствии с заданием лабораторной работы.
Реализован **вариант 4** - сигнал апериодического звена с формулой:

```
y(t) = k * (1 - e^(-t/T))
```

где:
- `k` - коэффициент усиления
- `T` - постоянная времени

## Структура проекта

```
lab7/
├── signal_generator.py    # Генерация сигнала и сохранение в CSV
├── mqtt_publisher.py      # Публикация данных из CSV в MQTT топик
├── mqtt_subscriber.py     # Подписка на MQTT топик и визуализация графика
├── requirements.txt       # Зависимости проекта
└── README.md             # Этот файл
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Порядок выполнения работы

### Шаг 1: Генерация сигнала

Запустите программу для генерации последовательности чисел, формирующей форму сигнала:

```bash
python signal_generator.py
```

Программа создаст файл `signal_data.csv` с данными сигнала.

### Шаг 2: Запуск издателя (Publisher)

Запустите программу для считывания CSV файла и публикации сообщений в MQTT:

```bash
python mqtt_publisher.py
```

Программа прочитает данные из `signal_data.csv` и отправит каждое значение в топик MQTT.

### Шаг 3: Запуск подписчика (Subscriber)

В отдельном терминале запустите программу для подписки на сообщения и отображения графика:

```bash
python mqtt_subscriber.py
```

Программа подключится к MQTT брокеру, подпишется на топик и будет отображать полученные значения на графике в реальном времени.

## Параметры MQTT

- **Брокер**: broker.emqx.io
- **Порт**: 1883
- **Топик**: lab7/signal_variant4

## Настройка параметров сигнала

В файле `signal_generator.py` можно изменить параметры сигнала:

```python
k = 10.0       # коэффициент усиления
T = 2.0        # постоянная времени (секунды)
duration = 10.0  # длительность сигнала (секунды)
dt = 0.1       # шаг дискретизации (секунды)
```
